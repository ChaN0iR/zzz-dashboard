# ZZZ 練度儀表板

絕區零（Zenless Zone Zero）代理人養成狀態的極簡儀表板。純 HTML / CSS / JS，沒有建置步驟，直接用 GitHub Pages 開啟即可，手機也能用。

## 功能

- 總覽：代理人數、平均建置分數、平均技能等級、未裝備音擎、音擎未滿 60、Lv0 驅動盤等統計
- 代理人列表：可搜尋、篩選、點欄位標題排序，每位有建置分數與「需注意」標記
- 代理人詳情：技能、音擎、6 片驅動盤（主詞條與副詞條）、最終數值皆可直接編輯，另有備註與優先度（主力 / 養成中 / 暫不養）
- 待辦：依優先度列出每位代理人的缺口
- 資料：匯出 / 匯入 JSON 備份，或重設為初始資料

## 建置分數（滿分 100）

音擎 30（有裝且 Lv60）、Lv15 驅動盤 40（片數 / 6）、技能 15、暴擊 15（暴擊率 x2 + 暴擊傷害，以 200 為滿）。純異常或支援角色的暴擊項會偏低，僅供參考。

「需注意」條件：沒有音擎、音擎未滿 60、有 Lv0 驅動盤，或分數低於 60。

## 資料

- 初始資料在 `data.js`，來自 HoYoLAB 戰績頁（繁體中文），已移除 UID 與暱稱。
- 修改內容只存在你瀏覽器的 localStorage，換裝置或清除瀏覽器資料前請先匯出備份。
- 影畫與音擎精煉為頁面上亮起的數量，副詞條強化次數與倉庫物品不在資料內。
