# ZZZ 練度儀表板

絕區零（Zenless Zone Zero）代理人養成狀態的極簡儀表板。純 HTML / CSS / JS，沒有建置步驟，直接用 GitHub Pages 開啟即可，手機也能用。

## 功能

- 總覽：代理人數、平均建置分數、平均技能等級、未裝備音擎、音擎未滿 60、Lv0 驅動盤等統計
- 代理人列表：可搜尋、篩選、點欄位標題排序，每位有建置分數與「需注意」標記
- 代理人詳情：技能、音擎、6 片驅動盤（主詞條與副詞條）、最終數值皆可直接編輯，另有備註與優先度（主力 / 養成中 / 暫不養）
- 待辦：依優先度列出每位代理人的缺口
- 資料：匯出 / 匯入 JSON 備份，或重設為初始資料
- 頂部固定列（每頁都有）：目前電量估算（每 6 分鐘 +1，上限 240，每 30 秒更新）、滿電時間、自訂目標（60 / 120 / 240 或任意數字）倒數，以及「更新讀數」（輸入遊戲內電量，時間為此刻）。時間一律以台北時間顯示。
- 電量列重新設計：一句話顯示電量與滿電時間、進度條、「什麼時候有 N 電量」（60 / 120 / 180 / 240 或自訂）、「預計用電」試算、「遊戲裡現在的電量」更新（0 到 240，有確認與錯誤訊息）
- 開啟遊戲按鈕（每頁右上）：在 iPhone 以 URL scheme 開啟，1.5 秒沒開成功會顯示 App Store 連結；scheme 可在「設定」修改（存 localStorage），預設 `zenlesszonezero://` 為推測值、未經驗證；電腦版無法使用
- 角色評分：每位代理人有建置類型（暴擊輸出 / 異常 / 支援 / 擊破 / 防護，依音擎與數值自動判斷，可手動改），依類型的有效副詞條權重算出角色分數，並標出有效詞條偏低的驅動盤與不符的 4 / 5 / 6 號位主詞條；原本的通用建置分數仍保留
- 下一步：每位代理人有可編輯的下一步欄位，留空時自動依缺口建議；主力的下一步會顯示在總覽與待辦
- 每日打卡：使用電量、刷的套裝、有用掉落、備註，含歷史清單
- 每週目標：文字、目標日期、完成勾選
- 活動與卡池日曆：手動維護，顯示開始 / 結束倒數
- 備份提醒：超過 30 天沒匯出時，頁面頂部顯示提示

## 建置分數（滿分 100）

音擎 30（有裝且 Lv60）、Lv15 驅動盤 40（片數 / 6）、技能 15、暴擊 15（暴擊率 x2 + 暴擊傷害，以 200 為滿）。純異常或支援角色的暴擊項會偏低，僅供參考。

「需注意」條件：沒有音擎、音擎未滿 60、有 Lv0 驅動盤，或分數低於 60。

## 資料

- 初始資料在 `data.js`，來自 HoYoLAB 戰績頁（繁體中文），已移除 UID 與暱稱。
- 修改內容只存在你瀏覽器的 localStorage，換裝置或清除瀏覽器資料前請先匯出備份。
- 影畫與音擎精煉為頁面上亮起的數量，副詞條強化次數與倉庫物品不在資料內。

## 電量資料格式

`data.js` 內的 `battery` 欄位（供排程更新覆寫）：

```
"battery":{"value":71,"at":"2026-10-14T15:00:00+08:00"}
```

`value` 為當時讀到的電量，`at` 為 ISO 8601 時間。載入時會與瀏覽器內的讀數比較，時間較新的一方生效；手動更新讀數會存進 localStorage。

## 匯出 / 匯入

匯出的 JSON 包含代理人（含建置類型與下一步）、電量讀數與目標、每日打卡（`checkins`）、每週目標（`goals`）、日曆（`events`）與上次匯出時間（`lastExport`）。舊版備份匯入時會自動補上缺少的欄位。
